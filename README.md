# Love · Flower

一个可定制花束与留言的立体礼物网页。静态运行，无需后端或 AI API 密钥。

## 使用

打开已部署的站点，点击信封读信、礼盒开合，使用底部按钮回正、开罩；移罩完成后可闻香。通过搭配面板编辑花材和寄语，确认后复制礼物链接。

## 请 AI 搭配

将正式站点首页与 [AI-GUIDE.md](AI-GUIDE.md) 一起交给 AI，说明送礼对象、关系、氛围和寄语要求。AI 在现有五种花材及预算内生成 JSON 和专属链接，不需要修改源码、fork 仓库或获取 GitHub 令牌。完整参数、预算与编码方式以指南为准。

支持玫瑰、郁金香、洋桔梗、马蹄莲和满天星；主花最多7朵，满天星最多8枝。所谓新花指新搭配，不支持通过链接注入新模型或代码。

## 隐私

寄语和配置保存在链接片段中，URI 编码不是加密。任何持有链接的人都能读取、转发其内容；没有撤回功能，请勿填入敏感信息。

## 部署

本目录仅含网页运行资源、AI 指南及许可。将目录内容置于 GitHub Pages 发布分支根目录，在仓库 Settings → Pages 选择对应分支与根目录。不需要构建步骤。正式站点地址以 Pages 实际发布结果为准。

需要启用 JavaScript 和 WebGL；移动浏览器表现与设备性能有关。不保证所有内嵌浏览器均可调用系统分享或保存到相册。
